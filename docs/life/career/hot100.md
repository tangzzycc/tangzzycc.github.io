## 哈希

### 1、[两数之和](https://leetcode.cn/problems/two-sum/)

给定整数数组 nums 和目标值 target，找出和为 target 的两个数的下标。 输入：nums = [2,7,11,15], target = 9 输出：[0,1]

**思路** ：用 Hash 表记录已遍历数字和下标，遍历时查找 target - nums[i] 是否存在。

```C++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> mp;
        for (int i = 0; i < nums.size(); ++i) {
            if (mp.find(target - nums[i]) != mp.end()) {
                return {i, mp[target - nums[i]]};
            }
            mp[nums[i]] = i;
        }
        return {};
    }
};
```

### 49、[字母异位词分组](https://leetcode.cn/problems/group-anagrams/)

给定字符串数组 strs，把字母异位词分到同一组。 输入：strs = [“eat”,“tea”,“tan”,“ate”,“nat”,“bat”] 输出：[[“eat”,“tea”,“ate”],[“tan”,“nat”],[“bat”]]

**思路** ：把每个字符串排序后作为 key，用 Hash 表收集同组字符串。

```C++
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        map<string, vector<string>> mp;
        for (auto& str : strs) {
            string now = str;
            sort(now.begin(), now.end());
            mp[now].push_back(str);
        }
        vector<vector<string>> ans;
        for (auto it : mp) {
            ans.push_back(it.second);
        }
        return ans;
    }
};
```

### 128、[最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)

给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。时间复杂度要求O(n) 。 输入：nums = [100,4,200,1,3,2] 输出：4 解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4

**思路** ：把所有数放进 Set，只从”没有前驱（num-1 不存在）“的起点出发，往后数连续长度，取最大值。

```C++
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> st(nums.begin(), nums.end());
        int ans = 0;
        for (int x : st) {
            if (st.find(x - 1) != st.end()) continue;
            int y = x + 1;
            while (st.find(y) != st.end()) y++;
            ans = max(ans, y - x);
            if (ans * 2 > st.size()) break;
        }
        return ans;
    }
};
```

## 双指针

### 283、[移动零](https://leetcode.cn/problems/move-zeroes/)

给定数组 nums，将所有 0 移到末尾，同时保持非零元素相对顺序。 输入：nums = [0,1,0,3,12] 输出：[1,3,12,0,0]

**思路** ：用慢指针依次放置非零元素，剩余位置补 0

```C++
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int idx = 0;
        for (int num : nums) {
            if (num != 0) nums[idx++] = num;
        }
        while (idx < nums.size()) nums[idx++] = 0;
    }
};
```

### 11、[盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)

给定高度数组 height，找出两条线能盛最多水的面积。 输入：height = [1,8,6,2,5,4,8,3,7] 输出：49

**思路** ：左右双指针计算面积，每次移动较短的一边

```C++
class Solution {
public:
    int maxArea(vector<int>& height) {
        int l = 0, r = height.size() - 1, ans = 0;
        while (l < r) {
            ans = max(ans, (r - l) * min(height[l], height[r]));
            if (height[l] < height[r]) {
                l++;
            } else {
                r--;
            }
        }
        return ans;
    }
};
```

### 15、[三数之和](https://leetcode.cn/problems/3sum/)

给定整数数组 nums，找出所有和为 0 且不重复的三元组。 输入：nums = [-1,0,1,2,-1,-4] 输出：[[-1,-1,2],[-1,0,1]]

 **思路** ：排序后枚举第一个数，再用左右指针找两数和并跳过重复值。

```C++
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> ans;
        for (int i = 0; i < nums.size() - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            int l = i + 1, r = nums.size() - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum == 0) {
                    ans.push_back({nums[i], nums[l], nums[r]});
                    while (l < r && nums[l] == nums[l + 1]) ++l;
                    while (l < r && nums[r] == nums[r - 1]) --r;
                    l++, r--;
                } else if (sum < 0) {
                    l++;
                } else {
                    r--;
                }
            }
        }
        return ans;
    }
};
```

### 42、[接雨水](https://leetcode.cn/problems/trapping-rain-water/)

给定柱子高度数组 height，计算下雨后最多能接多少水。 输入：height = [0,1,0,2,1,0,1,3,2,1,2,1] 输出：6

 **思路** ：双指针维护左右最大高度，每次结算较低侧能接的水。

```C++
class Solution {
public:
    int trap(vector<int>& height) {
        int l = 0, r = height.size() - 1, lm = 0, rm = 0, ans = 0;
        while (l < r) {
            lm = max(lm, height[l]);
            rm = max(rm, height[r]);
            if (lm < rm) {
                ans += lm - height[l++];
            } else {
                ans += rm - height[r--];
            }
        }
        return ans;
    }
};
```

## 滑动窗口

### 3、[无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

给定字符串 s，找出不含重复字符的最长子串长度。 输入：s = “abcabcbb” 输出：3 解释：最长无重复子串是 “abc”。

 **思路** ：滑动窗口配合字符最近位置，遇到重复字符就移动左边界

```C++
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int res = 0;
        unordered_set<int> st;
        int l = 0;
        for (int r = 0; r < s.size(); ++r) {
            while (st.find(s[r]) != st.end()) {
                st.erase(s[l]);
                l++;
            }
            st.insert(s[r]);
            res = max(res, r - l + 1);
        }
        return res;
    }
};
```

### 438、[找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

给定字符串 s 和 p，找出 s 中所有 p 的异位词子串起始下标。 输入：s = “cbaebabacd”, p = “abc” 输出：[0,6]

 **思路** ：维护长度为 p.length 的窗口计数，与 p 的计数相等时记录左端点。

```C++
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int n = s.size(), m = p.size();
        vector<int> ans;
        array<int, 26> cnt_s{};
        array<int, 26> cnt_p{};
        if (n < m) return ans;
        for (int i = 0; i < m; ++i) {
            cnt_s[s[i] - 'a']++;
            cnt_p[p[i] - 'a']++;
        }
        for (int i = 0; i < n - m + 1; ++i) {
            if (i != 0) {
                cnt_s[s[i - 1] - 'a']--;
                cnt_s[s[m + i - 1] - 'a']++;
            }
            if (cnt_s == cnt_p) {
                ans.push_back(i);
            }
        }
        return ans;
    }
};
```

## 子串

### 560、[和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

给定整数数组 nums 和整数 k，统计和为 k 的连续子数组个数。 输入：nums = [1,1,1], k = 2 输出：2

 **思路** ：用前缀和计数，当前位置需要找之前出现过的 prefix - k。

```C++
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> mp;
        mp[0] = 1;
        int res = 0, pre = 0;
        for (int i = 0; i < nums.size(); ++i) {
            pre += nums[i];
            res += (mp.count(pre - k) ? mp[pre - k] : 0);
            mp[pre]++;
        }
        return res;
    }
};
```

### 239、[滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)

给定数组 nums 和窗口大小 k，返回每个滑动窗口中的最大值。 输入：nums = [1,3,-1,-3,5,3,6,7], k = 3 输出：[3,3,5,5,6,7]

 **思路** ：用单调递减队列保存下标，队头始终是当前窗口最大值

```C++
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        deque<int> dq;
        vector<int> ans;
        for (int i = 0; i < nums.size(); ++i) {
            while (!dq.empty() && dq.front() <= i - k) {
                dq.pop_front();
            }
            while (!dq.empty() && nums[dq.back()] <= nums[i]) {
                dq.pop_back();
            }
            dq.push_back(i);
            if (i >= k - 1) {
                ans.push_back(nums[dq.front()]);
            }
        }
        return ans;
    }
};
```
