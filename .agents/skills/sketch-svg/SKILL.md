# 笔记 SVG 手绘图

沿用本仓库已经确定的绘图约定。先读相关正文和原图，明确这张图帮助读者理解的关系；新任务有明确要求时以用户要求为准。

## 固定视觉约定

- **保持可编辑 SVG。** 图形用矢量路径，标签保留 `<text>`；提供 `viewBox`、`title` 和 `desc`。
- **中文为主，保留英文术语。** 英文、数字使用 **Comic Shanns**；中文使用仓库的 **霞鹜文楷（LXGW WenKai GB Screen）**。按字符字体覆盖自动回退，混合标签也沿用这一规则。字体内嵌为 WOFF2，携带完整授权，不能依赖读者机器上的字体。
- **轻微手绘线条。** 使用 Rough.js 或等效的真实矢量手绘轮廓；固定随机种子，让重复生成可复现。不要只换字体，也不要给文字加抖动或滤镜。
- **较小字号。** 以最终页面显示宽度校准；常规标签约 13–15 显示 px，辅助标签约 11–12 px，标题约 16–18 px。先删冗余内容、调整布局，再解决拥挤；不要不断缩小正文标签。
- **保留有意义的配色。** 默认实色填充，轮廓轻微抖动。已有图优先保留原配色的对象语义和辨识度，不强制改成灰底、浅粉色或密集排线。
- **紧凑数学上下标。** 如 `Q_i`、`K_j^T`、`B_r`，下标贴近字母实际可见边缘；同时出现的上下标共用一列。使用工具的字形度量定位，不依赖等宽字的 advance、Unicode 下标字符或自动 `baseline-shift`。

具体参数、字号换算和本仓库参考图见 [视觉与布局约定](references/style-and-layout.md)。

## 内容与布局

一张图围绕一个理解难点组织。对象、操作、存储、逻辑视图各自明确；能用几何、颜色和位置表达的变化，避免重复写进文字框。不设置必备图数，重复正文或只有装饰作用的图可以删去。

矩阵标清必要的轴与尺寸；共享输入画一份再分叉。箭头从实际源对象连到目的对象，绕开标签。涉及实现、计算或调度时核对正文依据，区分概念示意与真实 trace、逻辑范围与实际存储；虚线的含义保持一致。

## 可复用工具

需要新建或重画 SVG 时，读 [工具用法](references/tools.md)：

- [prepare_fonts.py](scripts/prepare_fonts.py)：从标签文本或 SVG 提取字符，裁剪仓库中文字体，打包英文字体、授权与数学字形度量。
- [sketch_svg.cjs](scripts/sketch_svg.cjs)：生成实色手绘对象、连线、箭头、文本和紧凑上下标；自带 Rough.js 4.6.6，保留虚线属性。

这些工具负责字体和容易出错的几何细节，布局仍按具体内容设计。修订标签后重新生成字体包；不要把已有 SVG 中裁剪过的字体直接用于含新汉字的图。

## 渲染与交付

先检查对象关系、公式、尺寸、数值和箭头，再用 Chromium / Playwright 在预计显示宽度查看最终 SVG；确认两种内嵌字体实际加载、上下标紧贴且对齐、文字无越界和重叠。CairoSVG 可辅助检查，但不能据其回退字体截图确认 WOFF2 效果。验证方法见 [工具用法](references/tools.md#渲染检查)。

更新笔记时，在实际页面布局检查图片显示宽度、加载情况与窄屏表现。`width=1100` 仍可能被双栏容器压缩；确需通栏时调整该图所在布局，而非盲目放大字号。

最终 SVG 放入对应 `assets/` 主题目录，沿用可点击原图的引用方式。临时生成器、预览和检查记录留在工作目录或临时目录。仅要求编写技能时，交付技能及必要支持文件即可。
