# 课程机制插图

把教学过程画成读者能追踪的具体对象变化：数据如何产生、变换、共享、移动并得到结果。适用于计算、系统、网络等课程，不局限于 vLLM。

本技能记录的参考作品通过内置 `image_gen` 生成和多轮编辑。实际生图时配合可用的 `imagegen` 技能，遵守当前工具接口；本技能负责教学组织、提示词与正确性复核。

## 选择表达方式

- 用户希望复用参考图的形象表达时，优先用内置图片生成工具制作教学插图。不要默认退回到“文字框 + 箭头”。
- 用户要求可编辑 SVG，或仅需修改已有矢量源文件时，保留代码/矢量工作流；同样应用本技能的教学设计。
- “像动画一样”通常表示让一张静态图呈现连续状态，而非真正制作动画或添加人物、拟人角色。只有用户明确要求时才采用这些形式。
- 本用户的课程默认图内英文、正文中文；新任务有明确语言要求时以新要求为准。
- 参考图是视觉与过程示例，不是数学真值来源；不能直接复用其中的参数或假定所有细节已正确。

## 从内容到画面

1. **确定一句教学结论。** 例如“多个 Query 共享 K/V，但各自计算权重和输出”。先读对应正文；涉及实现时核对已选版本和路径。缺乏依据的内容用概念示意并标注，不能伪装成实际 trace。
2. **固定一个贯穿例子。** 写清输入、输出、维度/单位、对象身份与假设。前后比较使用同一输入、同一输出目标、同一计量口径；示意权重与手算结果要明确区分。
3. **列出对象及关系。** 哪些是操作数、运算、结果、存储、视图或副本？先把依赖弄清，再安排版面。共享源画一份后分叉；不同输出分别画；不要用箭头暗示一个操作数生成另一个操作数。
4. **将抽象过程映射到具体几何。** 向量画成带格子的条，矩阵画成带轴名的行列，缓存画成页与槽位，流水线画成对齐时间段，传输画出源和目的。宽度/高度若只是示意，要避免读者误以为严格按比例。
5. **确定视觉主线与局部展开。** 按因果依赖组织若干阶段；给最难理解的一步最多空间。用一致颜色、对象 ID 和一个高亮对象贯穿各阶段。优先让“图形如何变”承载含义，文字只解释必要标签与条件。

读者应该能沿图回答：当前看的是谁？它来自哪里？发生了什么变化？结果去哪了？

需要写生图或修订提示词时，读 [prompt-templates.md](references/prompt-templates.md)。需要复用参考作品的构图和纠错经验时，读 [attention-case.md](references/attention-case.md)，并查看其中链接的图片。

## 生成与迭代

- 区分参考图和编辑目标。对本地图片先查看；新图从教学规格生成，修订则引用上一张最合适的版本。调用参数以当前工具文档为准，不硬编码模型名、输出目录或不存在的尺寸参数。
- 首轮提示词一次给清教学目标、例子、分区、具体图形、准确标签、关键依赖与不变量。分辨率可以提出期望，但交付时核对实际尺寸。
- 首轮后先检查主线和对象关系，再纠正数学/标签，最后调整美观与布局；某一轮可以合并相互关联的少量修改。不要固定要求生成若干轮，合格即停止。
- 修订提示词明确“改哪里、怎样改、哪些内容保留”，例如“绿色 V 矩阵连入乘法框顶部；紫色权重仍从左进入”。不要只说“更清晰”“高级一点”。
- 修订后重新检查整张图。生图编辑可能顺带更改原本正确的公式、下标、箭头和高亮，不能只看指定修改区域。
- 同类精确错误经两次针对性修订仍未解决时，先减少图内标签、拆分复杂区域或更换可读写法，再继续。若工具仍无法可靠表现，说明具体限制并提出矢量重绘；不要无限重试或把错误图标成最终版。用户明确授权其他编辑方式前，图片编辑继续使用内置工具。

## 逐图复核

**语义与计算**

- 操作数分别进入操作节点，结果从节点流出；数据依赖、时间顺序和对象对应关系不要用同一种箭头含糊表达。
- 每条矩阵乘法的内维匹配；token/head/feature、请求/批次、逻辑/物理等轴或身份不混用。
- 共享输入不等于共享输出；分片不等于完整向量被截断；reshape/view 不暗示额外数学运算。
- 核对公式的负号、指数、分母、转置和下标；核对切片冒号与半开区间。不要因为公式“看起来像”就放过。
- 跟踪高亮对象从输入到结果的准确位置。源箭头必须从被选中的输出发出，目标高亮宽度必须与对应切片一致。
- 并行泳道要明确是概念展开还是实际调度。示意时间、概率和尺寸不冒充实测。

**阅读与排版**

- 在最终文档实际显示宽度查看一次，再放大检查细字。仅在原图放大时可读还不够。
- 关键路径一眼可见；颜色含义稳定，另有标签辅助；连接线绕开文字，分叉/汇合有明确目的地。
- 文字过密时先删冗余说明、让难点区域通栏或拆图，不用持续缩小字号解决。
- 公式出现在对应操作附近；不要给一排孤立公式让读者自行找对应关系。
- 图片放在正文正在解释该机制的位置。使用参考作品不意味着所有图都放在标题下，也不要求把多张图合为一张。

## 保存与交付

项目采用最终图 + 工作记录分离：将选定 PNG 保存到课程图片目录并更新引用；提示词、历史候选、检查记录留在工作资料中，除非用户要求，不混入只收最终 Markdown/图片的发布目录。

工作记录保留生成/编辑工具、所用参考图、实际提示词、关键修订、最终文件名和实际尺寸。只记录能核实的信息，不凭风格推断图片来源，也不把请求的分辨率写成实际分辨率。

交付时展示最终图片、链接保存文件，并说明尚存的具体限制。用户只要求记录方法或编写技能时，完成技能即可，不额外发起生图、改课稿或发布课程。
